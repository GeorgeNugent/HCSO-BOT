# Hendry County Project — Staff Dashboard

Static front-end starter for the HCP Staff Command Center.

## Files

- `index.html` — dashboard structure
- `style.css` — visual design
- `script.js` — simple navigation/placeholder behaviour
- `assets/` — reserved for HCP logos/images

## Current scope

This version intentionally contains **no real staff commands, Discord API, database, authentication, or moderation functionality**.

The navigation is ready so functionality can be added later.

## Run

Open `index.html` in a browser, or use VS Code Live Server.
